# Haritha Layomin - Portfolio Website

A professional, modern portfolio website built with React and Tailwind CSS, showcasing my journey from MERN/Laravel development to Enterprise Infrastructure and Cloud specialization.

## Features

- **Responsive Design**: Fully responsive for mobile and desktop
- **Dark/Slate Theme**: Tech-focused design with Azure Blue accents
- **Modern UI**: Clean, minimalist interface using Tailwind CSS
- **Interactive Elements**: Smooth scrolling navigation and hover effects
- **Professional Sections**: Hero, About, Experience, Projects, Skills, Roadmap, Footer

## Tech Stack

- React 18
- Tailwind CSS
- Lucide React (for icons)
- Vite (build tool)

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:5173](http://localhost:5173) in your browser

## Build for Production

```bash
npm run build
```

## Sections

- **Hero**: Introduction with name, headline, and call-to-action buttons
- **About**: Career transition story and current role
- **Experience**: Detailed work experience at MillenniumIT ESP and Bank of Ceylon
- **Projects**: Showcase of key projects including AI Dyslexia Tool, Student Portal, and Gem Management System
- **Skills**: Infrastructure and Development skills matrix
- **Roadmap**: 3-year certification plan (AZ-900, AZ-104, CCNA, AZ-305)
- **Footer**: Location and professional sign-off

## Customization

The website is fully customizable. Update the content in the respective component files in `src/components/`.
